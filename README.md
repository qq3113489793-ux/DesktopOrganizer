# 桌面收纳

一个原生 Windows 桌面收纳工具。每个分组都是独立的透明白色玻璃容器，可放入应用、快捷方式、文件和文件夹。

## 已实现

- 新容器默认 `2 x 2`，展开尺寸可按 96 DIP 图标网格调整到 `1 x 1`、`1 x 2`、`2 x 1` 等整数规格
- 容器内图标按方形半格网格自由落位，自动寻找最近的合法空位；图标三档 24 / 48 / 96 px 完整显示，不被格子高度压缩
- 拖动保持 1:1 跟手并实时显示目标格，松手严格落到预览位置
- 容器内图标按半格网格自由落位，自动寻找最近的合法空位
- 每个图标可单独右键切换“小 / 正常 / 大”三档
- 容器空白处右键可统一切换全部图标的“小 / 正常 / 大”三档
- 统一切换时会清除旧尺寸产生的冲突坐标，按项目顺序重新排列并自动补充网格空间
- 图标放大后空间不足时，容器自动扩展到最小可用尺寸
- 安卓文件夹式收纳：桌面项目（快捷方式、文件、文件夹）拖入分组即被收编——复制进分组内部收纳目录后桌面图标消失，任何 Explorer 显示设置下都彻底消失；拖出、右键移出或删除分组时安全恢复到桌面
- 从资源管理器等非桌面位置拖入的项目只保存引用，不移动原文件
- 右键图标菜单提供“打开文件所在位置”：快捷方式会定位到目标程序（exe）所在的真实文件夹，普通文件定位到自身所在文件夹
- 从容器拖到桌面时会传递拖放位置；自由排列时落在目标位置，自动排列、网格和排序模式由 Windows 桌面规则接管
- 小图标悬停快速显示完整名称
- 高分辨率 Windows Shell 图标，避免大图标直接放大低清资源
- 快捷方式优先读取目标程序图标；带透明留白的旧图标会按可见边界归一化，保证同一档位的视觉大小一致
- 图标和文字使用逐像素 Alpha 合成，不产生色键黑边
- 透明白色软件玻璃、圆角、细边框和实时外观调节面板；背景磨砂使用可调半径的软件模糊并与逐像素圆角在同一表面合成，`1%` 到 `100%` 连续变化，不再由固定强度的矩形 DWM 辅助层破坏圆角
- 拖动时玻璃实时跟手刷新，缩放用 16ms 平滑动画过渡到目标格；图标拖动使用独立覆盖层，落点以清透圆角格显示
- 分组收起为手机风格的 `104 x 104` 方形预览卡，2 x 2 显示前四个项目图标；双击原位展开
- 只有收起、启用“嵌入桌面网格”和“挤开桌面图标”时才占用一格并挪开该格内图标；展开只视觉放大，不挤占桌面格
- 不创建任何可见分组文件；旧版生成的归属明确的 `.desktoporganizer-group` 锚点会在升级后安全清理
- 容器默认自由移动，不被桌面图标网格束缚；拖动时靠近其他容器自动贴边、靠近屏幕边缘自动吸附（可选"嵌入桌面网格"让单个分组对齐桌面图标格）
- 容器固定在桌面底层，普通应用窗口始终显示在容器上方
- 系统托盘中新建、显示、隐藏容器和设置开机启动
- JSON 自动保存容器位置、尺寸、外观和图标排列
- 配置损坏可从 `.bak` 恢复；高版本或非法配置会拒绝覆盖，合法空配置不会自动复活默认分组
- 玻璃底图按位置、DPI 和外观参数缓存，悬停和图标动画不再重复执行整窗模糊
- Explorer 重启后自动恢复托盘图标、桌面层级和背景
- 多显示器及 DPI 变化后的可见区域修正

## 操作

- 拖动容器空白处移动，拖动边缘或四角改变网格行列数。
- 从资源管理器或桌面把项目直接拖进容器（桌面项目拖入后桌面图标消失并收编进分组，拖出时恢复桌面）。
- 拖动容器内图标调整位置，拖到其他容器可跨组移动；只有放到真实桌面区域才会移出分组。
- 双击图标打开；双击容器空白处或标题（名字）收起为预览卡，双击预览卡重新展开；右键图标调整它自己的大小或移出容器。
- 右键容器空白处打开外观设置、重命名、锁定、切换“嵌入桌面网格”、收起或新建分组。
- Windows 桌面空白处右键菜单提供“新建桌面分组”和紧随其后的“打开分组总控台”；前者在鼠标位置创建 `2 x 2` 玻璃容器，后者直接唤出正在运行程序的总控制台。
- 收起态是显示前四个项目图标的方形玻璃预览卡，展开态按保存的整数格尺寸恢复；两种状态都不会移动分组内的真实文件。
- Explorer 开启“自动排列图标”时不允许第三方程序移动原生图标，因此挤位功能会安全降级为不移动图标；分组自身仍保持网格对齐。

## 构建

需要 Visual Studio Build Tools 2026（使用 C++ 的桌面开发）和 CMake 3.24 以上。Visual Studio 安装器自带的 CMake 可以直接使用。

```powershell
cmake -S . -B build -G "Visual Studio 18 2026" -A x64
cmake --build build --config Release
```

生成文件位于 `build/Release/DesktopOrganizer.exe`。配置保存在 `%LOCALAPPDATA%/DesktopOrganizer/config.json`。

MSVC 的 C/C++ 运行库会静态链接进 EXE；Release 中的便携版不需要另行安装
Microsoft Visual C++ Redistributable。程序仍要求 Windows 10 或 Windows 11，
使用的 Direct3D、DWM 和 Shell 组件均为系统自带组件。

## 调试日志

程序会把启动、分组移动/缩放、图标拖入/移出、打开、解散、外观修改和配置保存错误记录到：

`%LOCALAPPDATA%/DesktopOrganizer/logs/DesktopOrganizer.log`

日志只记录操作结果和路径，不记录每一帧鼠标移动；写入失败不会中断用户操作。
当前日志达到 5 MB 后会轮换为 `DesktopOrganizer.previous.log`，旧的上一代日志会被覆盖，
两个文件合计最多约 10 MB。
